# DEV-TASK-002 · 残局拆弹手 / Last Round Defuse · v0.1

## 优先级
P0（Tina 已下令开发；制作人定稿锁定）

## 目标
Vite + Three.js + TypeScript 浏览器第一人称爆破回合原型，部署 GitHub Pages，交付可打开 HTTPS 地址。

## 名称与合规
- 游戏名：残局拆弹手 / Last Round Defuse
- 禁止 Valve / CS2 商标、地图、模型、音效

## 操作
WASD 移动、Shift 静步、Ctrl 蹲、空格跳、鼠标瞄准、左键射击、R 换弹、1/2/3 切枪（步枪/手枪/刀）、E 长按下包或拆包、Esc 暂停并解锁指针、点击画面锁定指针、整场按 R 重开（结算后或暂停菜单）。

## 规则（唯一有效规格）
- 首版**不做买枪经济**；每回合固定发步枪+手枪+刀。
- 比赛：共 8 回合；第 4 回合结束后交换攻守；先赢 5 获胜；4:4 平局。
- 每回合对战时长：**105 秒**；105 秒内未下包 → 守胜。
- 下包：A/B 包点内按住 E **3.0s**；松手或受伤进度清零。
- 拆包：按住 E **5.0s**；松手或受伤清零；无拆弹器。
- 下包成功后爆炸倒计时：**40 秒**；UI 改为显示爆炸倒计时；到 0 未拆完 → 攻胜。
- **包已下好后，进攻方全灭不判负**；守方必须拆包成功才算赢（或爆炸）。
- 尚未下包时任一方全灭 → 对方胜。
- 生命 100；爆头伤害 ×2（简化）。
- 阵亡后观战，显示「等待下一回合」。
- Esc 暂停；切标签页自动暂停。

## 内容范围
1. 原创港口仓库灰盒图，A/B 包点：地面**中性黄环 + A/B 字**，方向提示。
2. 配色：攻方橙帽/肩标，守方青帽/肩标（形状也不同）。
3. 1v1–3v3 AI，简单/普通两档；攻方 AI 会下包，守方 AI 会拆包。
4. HUD：点击开始/Esc、准星、血量、弹药、回合计时（下包后切 40s）、比分、A/B 箭头、「按住 E」+进度条、击杀提示、观战提示、开始/暂停/结算、中英切换。无购买 UI。
5. `npm run build` 通过；GitHub Pages 可玩；版本 `v0.1.0`。

## 不做
